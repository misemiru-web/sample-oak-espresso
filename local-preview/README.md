# OAK ESPRESSO｜ローカル確認用

このフォルダー内の`index.html`をダブルクリックしてブラウザで開いてください。Webサーバー、Node.js、インストール作業は不要です。

HTML・CSS・JavaScript・画像・favicon・LucideのインラインSVGを同梱しています。画像参照だけを`./images/...`へ変更し、本番用のデザイン・文章・機能をそのまま使用しています。preloadも同じ相対パスを参照します。現在の本番コードにはsrcset・CSS背景画像・外部フォントの参照はありません。

フォントは本番版と同じOS内のフォントとフォールバックを使用します。端末に入っているフォントによって書体が変わる点も本番版と同じです。画像・アイコン・言語切替はインターネット接続なしで使用できます。Googleマップ・Instagramの閲覧にはインターネット接続が必要です。

スクロール演出とマウス端末のホバーも本番版と共通です。表示済みの要素は繰り返し演出せず、OS・ブラウザの「動きを減らす」設定では省略します。JS無効時・アニメーションAPI非対応時も本文・写真を通常表示します。

別の場所や別のPCへ渡す場合は、`local-preview/`フォルダー全体をコピーしてください。`index.html`だけを移動するとCSS・JavaScript・画像が読み込めません。

## 本番用コードから再生成

リポジトリのルートで実行します（Python 3.8以上、追加パッケージ不要）。

```bash
python3 scripts/create-local-preview.py
```

本番用の`index.html`・`styles.css`・`script.js`・`images/`を読み取り、このフォルダーの確認用コピーを更新します。HTML・CSS・JavaScript内の`/images/...`だけを相対参照へ変換し、外部URLは維持します。画像とライセンス文書もコピーします。生成物を直接編集した場合は再生成時に上書きされます。

本番用ファイル、v1.1のルート相対参照、デプロイ設定は変更しません。このフォルダーは直接閲覧するための確認用で、本番用のエントリーファイルはリポジトリ直下の`index.html`です。

動作確認の詳細は`QA_REPORT.md`を参照してください。
