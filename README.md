## 内容

- `index.html`：日本語/英語切替のあるレスポンシブデザインプレビュー

- `screenshots/desktop_ja_full.jpg`：PC版の全ページデザインカンプ（日本語）

- `DESIGN_HANDOFF.md`：写真割り当て、デザイン判断、次工程のToDo

## 閲覧方法

1. ZIPを解凍して `index.html` をブラウザで開く。
2. 画面右上の `JA / EN` をクリックして言語を切り替える。
3. 画面幅に応じてレイアウトが変化する。画面下部のボタンはモバイル版の地図CTA。

ローカルサーバーで確認する場合：

```bash
cd oak_espresso_design_v1
python -m http.server 8000
```

その後 `http://localhost:8000/` を開く。

## 必ず確認すること

- **写真④・⑤**：依頼者が2026-10-18に「実際に店舗で使用・販売しているパッケージ」と確認済み。Roasteryセクションに採用した。
- **写真①**：2025年開業告知画像であり、正式なヘッダーロゴ素材とはみなしていない。見出しの「oak.」は**提案用タイポグラフィ**であり、公式ロゴのトレースではない。
- **ロゴ**：正式データが手に入れば置換する。
- **住所**：表記に差があり、掲載用の漢字表記について店舗へ最終確認する。
- **営業時間**：未確認の現行曜日・時間は掲載せずInstagramへ誘導している。
- **メニュー**：写真は過去の紹介素材。価格や常設提供を保証するコピーにしていない。
- **マップCTA**：現段階はGoogleマップの店舗名検索リンク。**Googleビジネスプロフィールの実店舗ピンへ直接遷移する正式リンクは未確定**。正式サイト・納品前には必ず確認して置換。
- **プレビュー公開**：`noindex`は検索回避の指示であり、アクセス制御ではない。商談相手だけに共有するならパスワード保護等を別途検討。
- **SNS素材**：店舗Instagram写真の使用許可は取得済み。第三者の印刷物や被写体の個別権利確認は必要に応じて行う。
